Репозиторий с сервисами и решениями студенческого финала.

## Структура таски

В каждом сервисе ожидается следующая структура:
```
- services/service_name/
  - service_name/ — код сервиса, *копируется на образ диска в 1:1*
  - checker/ — чекер
  - sploits/ — эксплоиты для внутреннего использования
  - vulns.md — описание уязвимостей
```
